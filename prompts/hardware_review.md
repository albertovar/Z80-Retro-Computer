# Prompt — Hardware / KiCad Review
Review the actual schematic/PCB/netlist.
1. Identify component refs, pins, nets and polarity.
2. Separate schematic facts from assumptions.
3. Derive logic equations and truth tables.
4. Check active-low/high enables and resets.
5. Explain fault mechanism before suggesting board changes.
6. Prefer minimal fixes for fabricated PCB.
7. Give practical multimeter/continuity/LED/switch tests.
8. State exact missing evidence instead of guessing.
9. Update docs only after confirmation or validated test.
